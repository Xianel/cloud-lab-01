# cloud-lab-01

Практическая работа: веб-приложение на Node.js и Express, разработанное в GitHub Codespaces.

## Запуск

```
npm install
npm start
```

Сервер запускается на http://localhost:3000 (порт можно изменить переменной окружения PORT).

## Маршруты

- `GET /` — стартовая страница
- `GET /api/status` — состояние сервера (имя приложения берётся из переменной окружения APP_NAME)
- `GET /api/services` — список сервисов
- `GET /api/services/:id` — сервис по идентификатору, 404 если не найден
- `POST /api/services` — добавление сервиса: `{"name":"...","category":"..."}`, возвращает 201; без полей — 400
- `GET /api/hello?name=Anna` — приветствие, без параметра name возвращает «Гость»
